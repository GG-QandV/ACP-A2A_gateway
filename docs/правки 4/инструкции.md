

# Инструкция для агента

**Задача**: Реализовать журнал для юзера + запоминание апрувов.

**Срок**: Сейчас.

***

### 1. Применить патч

```bash
# Перейти в репозиторий
cd gatewayd

# Применить патч
git apply 001_journal_and_approvals.patch

# Проверить, что файлы создались
ls src/journal.rs src/approved_agents.rs

# Скомпилировать
cargo build
```

***

### 2. Что делает патч

**Новые файлы**:

- `src/journal.rs` — запись в `journal.jsonl`
- `src/approved_agents.rs` — хранение апрувов в `approved_agents.json`

**Обновлённые файлы**:

- `src/main.rs` — апрув + журнал
- `src/config.rs` — `journal.path`, `logs.path`
- `Cargo.toml` — зависимости (`chrono`, `serde_json`)

***

### 3. Тестирование

```bash
# 1. Создать config.yaml
cat > config.yaml <<EOF
agents:
  - name: claurst-main
    url: http://localhost:8348
    token: t-dev-local-001

journal:
  enabled: true
  path: journal.jsonl

logs:
  enabled: true
  path: gatewayd.log
  level: info
EOF

# 2. Запустить шлюз
cargo run

# 3. Проверить журнал
cat journal.jsonl

# 4. Проверить утверждённые агенты
cat approved_agents.json

# 5. Перезапустить шлюз
cargo run
# claurst-main уже разрешён (не спрашивает)
```

***

### 4. Если что-то не работает

**Ошибка**: `journal.jsonl не создаётся`

**Решение**: Проверить, что `journal.enabled: true` в `config.yaml`.

**Ошибка**: `approved_agents.json не читается`

**Решение**: Удалить файл, шлюз создаст новый.

**Ошибка**: `cargo build не компилируется`

**Решение**: Проверить, что `chrono` и `serde_json` в `Cargo.toml`.
